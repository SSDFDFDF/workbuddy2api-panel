1怎么组合 决定网关提示词与客户端 system 谁在前、谁留
2用什么内容 三者优先级：内联正文 > 文件 > 预设
3按域覆盖（可选） 只给某一类账号用不同提示词 留空 = 继承第 1 / 2 步
素材规则：任一域显式设了预设/文件/正文，该域素材就完全由自己的设置决定（不半继承）；组合位置则逐项回落顶层。
4预览生效正文

多模态与图片 工具结果图片 · 格式转码 · 体积压缩

即时生效
工具结果图片
图片转码与压缩（默认全关）
格式转码（gif / bmp / tiff → PNG）
上游只原生接受 jpeg / png / webp；其余格式原样透传会被拒。开启后网关解码重编码： GIF 只保留首帧，重编码后仍超 5 MiB 会明确报错（可配合下方压缩档）。关闭时不解码图片。
! 以上两项是显式声明的兼容变换：会改变出站图片字节（有损），与原生 Chat 的逐字透传契约不同。 默认全关时请求路径不解码图片，只做形状与 5 MiB 硬限制校验。

即时生效

启用指纹改写
上游按逐字拒绝的已知串（Claude Code / Codex 身份句、x-anthropic-billing-header 键值、裸 11128 等） 只出现在 system/developer 时，组合提示词就能处理；但若藏在 user/assistant/tool 消息里时只能靠本项逐字改写。
! 会修改用户可见内容（如对话里的 11128 变成 11-128、命中的词句被替换）。 只用于绕过上游字面拒绝，不是内容治理。默认关闭；开关与规则都即时生效，无需重启。

访问日志记录
